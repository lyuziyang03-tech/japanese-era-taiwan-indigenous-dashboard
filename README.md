# 日治時期歷年原住民戶口可視化（1906-1942）

## 簡介

本專案使用 **Streamlit** 建立互動式 Dashboard，展示《臺灣五十一年來統計提要》中「表53 歷年高山族戶口」資料（http://twstudy.iis.sinica.edu.tw/twstatistic50/index.htm）。

使用者可以透過側邊欄選擇不同分析模式，查看單一年份的族群結構，以及 1906-1942 年間各族群人口變化趨勢。

本研究以泰雅族人口變化作為分析核心。因此，除展示整體高山族人口趨勢外，也特別分析泰雅族與其他族群之間的人口差異與變化。

---

## 資料來源

資料來源：

《臺灣五十一年來統計提要》

內容：
- 表53：歷年高山族戶口
- 時間範圍：1906-1942年

資料包含：

- 高山族總人口
- 男性人口
- 女性人口
- 各民族人口
- 有配偶者
- 壯丁數

---

## Dashboard 功能設計

本 Dashboard 提供兩種主要分析模式，使用者可以透過側邊欄自由切換分析方式與資料範圍。

### 1. 單一年份分析

使用者可選擇特定年份，查看該年度高山族人口結構。

主要功能包括：

- 年份基本資料摘要
  - 戶數
  - 高山族總人口
  - 男性人口
  - 女性人口
  - 有配偶者
  - 壯丁數

- 各族群人口比較圖
  - 顯示泰雅族、賽夏族、布農族、鄒族、排灣族、阿美族、雅美族及其他族群的男性、女性與總人口數。

- 族群結構摘要
  - 泰雅族人口數
  - 泰雅族占高山族總人口比例
  - 人口最多族群
  - 泰雅族男女比例

---

### 2. 歷年趨勢分析

使用者可選擇年份範圍，觀察1906年至1942年間高山族人口變化。

主要功能包括：

- 各民族與高山族總人口變化趨勢
  - 比較不同族群人口隨年代的增減。

- 泰雅族性別人口變化
  - 分析泰雅族男性與女性人口長期變化。

- 年代變化摘要
  - 泰雅族人口增長率
  - 高山族總人口增長率
  - 泰雅族占總人口比例變化
